# ميزان المحاسبة

نظام محاسبي متكامل لإدارة الشركات والمؤسسات، ويشمل:
- الحسابات العامة
- دفتر اليومية
- دفتر الأستاذ
- الفواتير
- المشتريات
- المصروفات
- المبيعات
- العملاء والموردين
- المخزون
- التقارير المالية
- المستخدمين والصلاحيات
- إعدادات الشركة

## التقنيات
- Next.js 14
- TypeScript
- Tailwind CSS
- Prisma ORM
- SQLite

## التشغيل

```bash
npm install
npx prisma db push
npm run db:seed
npm run dev
```

## رابط التطبيق
http://localhost:3000
